# CloudCart — Multi-Microservice GitOps Platform on AWS EKS

CloudCart is a production-grade DevOps project that demonstrates deployment of a multi-microservice application on AWS EKS using Terraform, Docker, GitHub Actions, Helm, Argo CD, RDS PostgreSQL, Redis, SQS, CloudWatch, Prometheus, and Grafana.

## Project Goals

- Build a multi-microservice application
- Containerize all services using Docker
- Provision AWS infrastructure using Terraform
- Deploy services to Amazon EKS using Helm
- Implement GitOps deployment using Argo CD
- Use Amazon RDS PostgreSQL for persistent storage
- Use Redis for caching
- Use Amazon SQS for asynchronous communication
- Implement CI/CD using GitHub Actions
- Add monitoring and logging using CloudWatch, Prometheus, and Grafana
- Demonstrate autoscaling, rollback, and production-grade Kubernetes practices
